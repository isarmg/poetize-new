# Poetize v3.0.0

本次发布将服务端更新为 Rust、Axum、SQLite，前端更新为 React、TypeScript。前台根据最新的 poetize.cn 页面重新调整导航、首页栏目、页面布局、图片和交互细节；管理后台继续使用项目自己的 Web 实现和样式。

新版本提供文章与分类、评论和收藏、友链、音乐、旅拍、恋爱笔记、会员与聊天，以及内容和站点管理。Linux x86-64 发布包包含服务程序与构建好的 Web 文件，并附 SHA-256 校验文件。

**升级提醒：**此版本的数据层与旧版 Java/MySQL 不兼容，暂不提供自动迁移。请保留旧版数据库及媒体文件备份，按发布包 README 初始化新的 SQLite 数据库，再导入所需内容。
