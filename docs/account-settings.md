# 修改当前账号

后台右上角的人物图标进入普通账号设置页面，与其他菜单共用后台工作区；人物图标保持原样，不增加选中标记或下划线。页面提供用户名（默认当前用户名）、当前密码、新密码、确认新密码和保存按钮。

保存时先验证当前密码，再原子更新账号；新密码留空则保留原密码，填写时需符合长度要求并两次输入一致。错误仅显示用户提示，不显示请求标识。失败或离开页面时清除密码；成功后使用新账号信息重新登录，旧会话失效。账号组件、主题和样式直接使用正式 xcss npm 包并锁定 tarball 与 integrity。

登录页保留灰色内容块和浅色下的黑色文字，提供深浅色切换；语言和主题图标尺寸与后台相同，主题选择在刷新、登录和退出后保持。
